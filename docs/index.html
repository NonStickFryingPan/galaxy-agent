How It Works

Galaxy-agent does exactly what you do: real analyses, start to finish.
Ask in plain language; route the heavy steps to Galaxy.

  1. Creates History: Agent comes in, creates a history on Galaxy (you name it).
  2. Smart Ingestion: It uploads your files from disk, or via links and servers intelligently.
  3. Discovers & Plans: It asks what you are doing, discovers tools on Galaxy, and tells you the plan (e.g., running FASTQC with these parameters).
  4. HITL Approval: You approve it, and it goes ahead and does the thing.
  5. Flexible Results: Results come back—you can click the link to see them ON GALAXY SERVER, or ask it to download them locally and inspect via local tools.
  6. Dedicated Modes: You have access to local tools and bash commands all the way via dedicated bash mode ($) versus normal chat mode (>).
Here is how it actually works in practice: You launch galaxy-agent in your terminal. It connects to Galaxy and creates a dedicated history—you name it whatever you like. Next, ingestion: it uploads your files from local disk, or pulls them intelligently straight from remote servers or links. It asks what you want to achieve, dynamically discovers the necessary tools on Galaxy, and lays out the exact execution plan—for example, running FastQC with specific adapter settings. You approve it, and it executes the job on Galaxy compute. When results finish, you have complete flexibility: click the link to inspect them directly on the Galaxy server, or ask the agent to download them locally to run local analysis. And throughout the entire session, you can switch seamlessly between normal chat mode and dedicated bash mode to run local terminal commands anytime.
